# Data Policy

**Do not commit to this repository:**

- Giant datasheet collections
- Copyrighted document archives
- Proprietary company documents
- Confidential project files
- NDA-protected information
- API keys, credentials, or secrets

This also means: no proprietary Hawee project files and no internal ABB material belong in this repository.

## What eventually belongs here

- Metadata
- Small, license-permitted sample datasets
- Ingestion instructions
- Manifests
- Test fixtures

Where licensing allows, prefer downloading/ingesting external documents (datasheets, application notes, etc.) through reproducible scripts or documented setup steps, rather than committing the documents themselves.

No data exists here yet as of project initialization.
