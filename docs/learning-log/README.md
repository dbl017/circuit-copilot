# Learning Log

This folder documents what I actually learn while building CircuitCopilot. It is intentionally part of the portfolio — the goal is to be able to speak concretely about what was built, what was misunderstood, and what changed as a result.

## When to add an entry

Add an entry after learning or implementing something non-trivial: a new concept, a milestone capability, a debugging session that revealed something important, or a decision that changed how a piece of the system works.

## Entry format

Name files descriptively, e.g. `2026-09-kicad-ipc-basics.md`, and try to answer:

1. What is this concept?
2. Why does CircuitCopilot need it?
3. What did I implement?
4. What did I misunderstand initially?
5. What failed?
6. What did I learn?
7. What would I explain in an interview?

Entries don't need to be long or polished — the point is an honest record, not a blog post.
