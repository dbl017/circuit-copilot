# Research Notes

This folder holds background research that informs CircuitCopilot's design — things like notes on the KiCad IPC API, comparisons of RAG/embedding approaches, agent framework evaluations, or relevant papers and prior art.

This is separate from Architecture Decision Records (`docs/decisions/`): research notes capture what was learned and considered, while ADRs capture what was ultimately decided and why. Research notes are also separate from the Learning Log (`docs/learning-log/`), which is a personal record of what was learned while building each capability.

No research notes exist yet as of project initialization. Add files here as investigation happens, named descriptively (e.g. `kicad-ipc-api-notes.md`, `rag-approaches-comparison.md`).
